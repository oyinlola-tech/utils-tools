About

Built for the work you do, quietly and privately.

Utils-tool is a collection of file utilities — image compression, PDF tools, developer assets, and more — that run on your machine. No accounts, no cloud uploads, no tracking. Just fast, precise tools that respect your workflow.

The problem we're solving

Every designer, developer, and content creator has the same recurring task: shrink a PDF before sending it, strip a background from a product photo, resize images for a social post, or generate a favicon set from a single SVG. Each of these is a quick, private job — but the tools that handle them either require an account, upload your files to a server, or cost more than they should.

Utils-tool was built to fill that gap. It is a single application that brings the utilities you use every day behind one calm, consistent interface. You run it locally, your files never leave your machine, and the output is always under your control.

Principles

Designed around your needs, not ours.

Every decision in Utils-tool comes back to three principles.

Privacy first

Nothing leaves your computer unless you tell it to. No uploads, no analytics, no telemetry. Your files stay yours from the first click to the final download.

Calibrated output

Tools expose meaningful settings — quality sliders, format selection, target file sizes. You decide how the result looks, not a black box.

Built to last

A consistent interface across all tools, powered by battle-tested libraries. Self-host it, extend it, or run it in your browser — the code stays open and readable.

Under the hood

Modern tools, minimal footprint.

The same libraries trusted by developers worldwide, running locally on your machine.
