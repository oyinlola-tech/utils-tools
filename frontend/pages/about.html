About

Built for the work you do, quietly and privately.

Utils-tool is a free, open-source collection of file utilities — image compression, PDF tools, developer helpers and more — behind one calm, consistent interface. No accounts, no ads, no watermarks, and nothing kept longer than it has to be.

The problem we're solving

Every designer, developer, and content creator has the same recurring task: shrink a PDF before sending it, strip a background from a product photo, resize images for a social post, or generate a favicon set from a single SVG. Each of these is a quick, private job — but the tools that handle them either require an account, upload your files to a server, or cost more than they should.

Utils-tool was built to fill that gap. It brings the utilities you use every day behind one consistent interface. Many tools run entirely in your browser; the ones that need a server delete your file automatically, and you can run the whole thing on your own machine so nothing leaves it at all.

Principles

Designed around your needs, not ours.

Every decision in Utils-tool comes back to three principles.

Privacy first

Browser-based tools never upload anything. Server tools keep your file only while they work on it, and output links are random. No accounts, no ads, no selling data.

Calibrated output

Tools expose meaningful settings — quality sliders, format selection, target file sizes. You decide how the result looks, not a black box.

Built to last

A consistent interface across all tools, powered by battle-tested libraries. Self-host it, extend it, or just use the hosted site — the code stays open and readable.

Under the hood

Modern tools, minimal footprint.
