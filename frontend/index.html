Where your files go.

Straight answers, not a slogan.

In your browser
Editors, croppers, encoders, generators and the text tools run entirely on your device. Those files never leave it.
On the server
Compression, conversion and PDF work are sent to this site's server, processed, and deleted automatically within about 30 minutes. Output links are random and unguessable.
Never
No accounts, no ads, no selling data, no keeping your files. The code is open source, so you can check — or run it on your own machine.

Questions.

Something missing? Open an issue on GitHub.

Is Utils-tool really free?

Yes. There are no paid tiers, no watermarks on your files and no account. If it saves you time, you can support the project with the heart button.

Are my files uploaded?

Only for tools that need the server, such as compression and PDF processing. Those files are deleted automatically within about 30 minutes. Browser-based tools never upload anything.

How large can my files be?

Each tool shows its limit on the upload box. The hosted site accepts files up to about 4 MB per request because of the hosting platform; run Utils-tool on your own machine for files up to 100 MB.

Which file formats work?

Images (JPG, PNG, WebP, AVIF), PDF, SVG, JSON, CSV, ZIP and plain text, depending on the tool. Drop a file in the inspector above to see which tools accept it.

Can I process several files at once?

Yes. Most image and PDF tools take a batch — add files, reorder them where order matters (like merging PDFs), and download everything together.

Can I run it myself?

Yes. It's open source: clone the repository, install the requirements and start it with ./start.sh. Locally every tool is available, including background removal and video downloads.
